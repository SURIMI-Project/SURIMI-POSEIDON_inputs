# SURIMI-POSEIDON_inputs

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC_BY_4.0-lightgrey.svg)](LICENSE)
[![Sync repo to S3](https://github.com/SURIMI-Project/SURIMI-POSEIDON_inputs/actions/workflows/s3-sync.yml/badge.svg)](https://github.com/SURIMI-Project/SURIMI-POSEIDON_inputs/actions/workflows/s3-sync.yml)

Input data for the POSEIDON agent-based fisheries model, as used in the SURIMI project by
[SURIMI-POSEIDON](https://github.com/SURIMI-Project/SURIMI-POSEIDON). The files are
generated by the SURIMI data preprocessing pipelines; do not edit them by hand.

## Sources

### Northwestern Mediterranean (`northwestern_med/`)

| File | Derived from |
| ---- | ------------ |
| `bathymetry_grid.asc`, `exclusion_grid.asc` | NWMed EwE model grid; GEBCO (land elevations only) |
| `french_eez.asc` | NWMed EwE model grid; GEBCO; Marine Regions EEZ |
| `habitat_grids.nc` | NWMed EwE model grid; habitat maps |
| `mpa_grids.nc`, `mpa_months.csv`, `mpa_fleet_restrictions.csv` | NWMed EwE model grid; MPA closures |
| `port_closures.csv` | Port closures |
| `biomass_grids.nc` | NWMed EwE model and Ecospace biomass maps; FAO ASFIS; FDI |
| `species.csv`, `discard_ratios.csv` | NWMed EwE model; FAO ASFIS |
| `target_landings.csv` | NWMed EwE model; FAO ASFIS; FDI |
| `fleet_register.csv`, `ports.csv` | EU Fleet Register; EMODnet first sales; GFCM geographical subareas |
| `prices.csv` | EMODnet first sales; EU Fleet Register; GFCM geographical subareas; NWMed EwE model; FAO ASFIS |
| `operating_costs.csv` | STECF Annual Economic Report |

**NWMed EwE model** (Ecopath with Ecosim model of the northwestern Mediterranean, its Ecospace grid and
biomass maps), by Marta Coll, Jeroen Steenbeek and colleagues:

- Corrales, X., Coll, M., Tecchio, S., Bellido, J.M., Fernández, Á.M., Palomera, I. (2015). Ecosystem
  structure and fishing impacts in the northwestern Mediterranean Sea using a food web model within a
  comparative approach. *Journal of Marine Systems* 148, 183–199.
  https://doi.org/10.1016/j.jmarsys.2015.03.006
- Coll, M. et al. (2024). Mechanistic projections for changing species and ecosystems: preliminary
  projections and report. *FutureMARES Deliverable Report* 4(4), 1–285.
  https://digital.csic.es/handle/10261/412296

**Habitat maps, MPA closures and port closures**: provided by Miquel Ortega (Institut de Ciències del Mar, ICM-CSIC).

**GEBCO**: GEBCO Compilation Group (2025) GEBCO 2025 Grid (doi:10.5285/37c52e96-24ea-67ce-e063-7086abc05f29).
Public domain. Not to be used for navigation.

**Marine Regions EEZ**: Flanders Marine Institute (2023). Maritime Boundaries Geodatabase: Maritime Boundaries
and Exclusive Economic Zones (200NM), version 12. https://www.marineregions.org/.
https://doi.org/10.14284/632. CC BY 4.0.

**FAO ASFIS**: FAO. ASFIS List of Species for Fishery Statistics Purposes.
https://www.fao.org/fishery/static/ASFIS/ASFIS_sp.zip. CC BY 4.0.

**FDI**: European Commission, Joint Research Centre (2025). Fisheries Dependent Information: effort,
landings, catches, capacity and biological data. http://data.europa.eu/89h/bf5c5f9a-87d6-4470-a380-458347b7813a.
Data quality and completeness are the responsibility of the Member States.

**STECF Annual Economic Report**: Scientific, Technical and Economic Committee for Fisheries (STECF) – The
2025 Annual Economic Report on the EU Fishing Fleet (STECF 25-07), JRC144396.
https://stecf.ec.europa.eu/data-dissemination/aer_en

**EMODnet first sales**: downloaded from the EMODnet Portal (https://emodnet.ec.europa.eu/en/); data
originator Cogea Srl. Dataset EMODnet_HA_Fisheries_FirstSales_20250319. CC BY 4.0.

**EU Fleet Register**: European Commission, DG MARE, Union Fleet Register.
https://webgate.ec.europa.eu/fleet-europa/search_en

**GFCM geographical subareas**: FAO General Fisheries Commission for the Mediterranean.
https://www.fao.org/gfcm/data/maps/gsas/en/. Used only to select ports; no GSA geometry is published here.
